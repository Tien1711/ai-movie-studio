        Đang dùng đang kiểm tra…

        Studio kết nối với URL và khóa Muse2API được cấu hình trên máy chủ.

        Dùng phiên Muse đăng nhập sẵn trong Chrome

        Mở Chrome profile bạn muốn dùng. Vào chrome://extensions, bật Chế độ dành cho nhà phát triển và chọn Tải tiện ích đã giải nén từ thư mục chrome-muse-profile trong dự án.

        Mở tiện ích AI Movie Studio – Muse Profile trong profile đó, đặt tên và dán mã vừa tạo. Giữ tab Muse mà tiện ích mở rồi tải lại danh sách và chọn profile ở đây.

        Thiết lập gateway Browser lần đầu

        Cài Muse-Chat-MCP. Điền MUSE_CHAT_MCP_DIR và MUSE_BROWSER_KEY trong .env của Studio.

        Chạy node --env-file=.env scripts/muse_browser_gateway.mjs trong thư mục Studio rồi đăng nhập Muse ở trình duyệt mà gateway mở.
